# Tool icon sources

SVG logos for Revit, AutoCAD, Archicad, Fusion 360, Rhino, SketchUp, V-Ray, and Adobe tools were retrieved through the Iconify API (The SVG, Logos, and Streamline Logos collections). QGIS uses Simple Icons. Microsoft Project uses the dashboard-icons collection.

Navisworks, Grasshopper, Lumion, D5 Render, and Enscape are locally recreated vector marks based on the previous supplied reference icons. They are approximations rather than official brand artwork. Lumion uses a text wordmark with system font fallback.

All rendered tool icons are local SVG files with vector shapes, not embedded raster images. Superseded PNG files have been removed.
